# Writing vault

A starter vault for pablo. Copy this directory somewhere of your own, make it a git
repository, and run `pablo init novel <slug> "<Title>"` inside it. pablo adds a row for
each new work to the table below.

`style/prose.md` and `style/anti-tells.md` are sent to the writer with every chapter,
so they are where your taste lives. These are a starting point: rewrite them in your
own words. A line starting `Flagged:` in `prose.md` is an example you rejected;
`pablo check` reports any draft that repeats one.
