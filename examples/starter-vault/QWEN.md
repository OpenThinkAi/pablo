# Writing vault

Shared rules for every work in this vault. Each work has its own `STYLE.md` that adds
rules for that work; both apply, and where they conflict the work's file wins.

## Prose rules that apply everywhere

The full guide with examples is `style/prose.md`; the list of things that make text
read as machine-written is `style/anti-tells.md`. Edit both to make them yours.

## Vault layout

    QWEN.md          this file: shared rules
    style/           prose.md, anti-tells.md: the shared style guide
    templates/novel/ what `pablo init novel` copies for a new work
    novels/<slug>/   one directory per novel
